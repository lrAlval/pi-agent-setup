# uix - UI build workflow
## Activation
Activate for `/uix`, trigger phrases, or make/build/improve a screen, page, landing page, or dashboard intent.
## Tiering
- trivial: <=20 LOC, style-only, no DOM; skip gates.
- light: <=200 LOC, one screen; contrast, semanticHtml, metaTags.
- production (default): all BLOCK gates.
## Playbooks
Read the corresponding file verbatim: `skills/uix-activate.md`, `uix-build.md`, `uix-dashboard.md`, `uix-verify.md`, `uix-refine.md`, `uix-componentize.md`, `uix-parity.md`, `uix-annotate.md`, `uix-iterate.md`, `uix-figure-out.md`, `uix-feature.md`.
## Checkpoints
1. Brief and visual direction lock.
2. Post-build screenshot review.
3. Pre-ship gate summary.
Skipped checkpoint = INCONCLUSIVE, never pass. Proceed with reversible work, then confirm.
## Routing discipline
Read selected playbook fully before acting. Missing file = stop and report. Never route from memory.
